# Online Quiz System

Online Quiz System is a web-based application that allows users to attend quizzes and view their scores instantly.

## Features
- User Registration & Login
- Multiple Choice Questions
- Quiz Timer
- Instant Result & Score Display
- Admin Panel for Managing Questions

## Technologies Used
- PHP
- MySQL
- HTML
- CSS
- JavaScript

## Purpose
This project helps users test their knowledge online in a simple and interactive way.
